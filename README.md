## 主な機能 (Features)

### ローカル処理による安全性
画像処理および変換はすべてブラウザ上で完結します。外部サーバーへのデータ送信は行われません。
社内資料や機密情報を含む画像なども、ローカル環境のみで処理が可能です。

### リサイズとフォーマット変換
* **画像読み込み**: ドラッグ＆ドロップによる複数画像の読み込みに対応しています。HEIC / HEIF 形式の画像は自動で変換されます。
* **サイズ調整**: 定番のアスペクト比（16:9, 4:3, 1:1など）、縦長・横長の指定、ピクセル単位でのサイズ指定（比率固定を含む）が可能です。
* **フォーマット変換**: `PNG` `JPEG` `WebP` 形式での出力に対応しています。

### 描画・アノテーション（注釈）機能
* プレビュー画像をクリックすると専用エディタが起動します。
* **ツール類**: ペン、直線、矢印、丸枠、四角枠、テキスト入力、塗りつぶし（黒塗り）、消しゴムを使用できます。
* **テキスト編集**: 文字の移動、拡大縮小、回転、フォントおよびカラーの変更が可能です。
* **操作機能**: 指定キーの長押しによる一時的なツール切り替え（ホールド切替）や、マウスホイールによるサイズ調整、Undo（戻す）/ Redo（進む）機能に対応しています。

### 画像結合機能
* 処理済みの画像を選択して「結合トレイ」に追加し、1枚の画像としてまとめることができます。
* 「縦結合」「横結合」「4方（2x2）結合」をサポートしています。

### 一括リネームとZIP保存
* **ファイル名設定**: 「接頭辞 (Prefix)」「元のファイル名」「連番」「接尾辞 (Suffix)」を組み合わせて出力ファイル名を設定できます。
* **ZIP保存**: 処理した複数の画像を、一つのZIPファイルにまとめてダウンロード可能です。

### UI設定
* **表示モード**: ダークモードへの切り替えに対応しています。
* **テーマカラー**: アクセントカラーや背景色を変更でき、設定は最大3つまでプリセットとして保存可能です。
* **レイアウト調整**: 表示スタイル（グリッド/リスト）やプレビューカードのサイズを調整できます。設定はブラウザに自動保存されます。
